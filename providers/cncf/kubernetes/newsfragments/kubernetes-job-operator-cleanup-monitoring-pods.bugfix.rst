Fix pod cleanup gaps in ``KubernetesJobOperator``: ``execute()``, ``execute_complete()`` and ``on_kill()`` now consistently clean up pods discovered via ``get_pods()``, including deferrable resume paths where pod lookup can fail. The inherited ``on_finish_action`` parameter (``delete_pod`` / ``delete_succeeded_pod`` / ``keep_pod``) is honoured for these pods, matching ``KubernetesPodOperator`` behavior. Per-pod cleanup errors are logged but never mask a Job-level failure.
